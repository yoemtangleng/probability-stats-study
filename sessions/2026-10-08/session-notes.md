# 补充：第二章 2.1 随机变量——分布律 vs 分布函数（同日晚些时候的引导式对话）

## 讨论的问题

### 问题1："概率分布率"和"分布率"是一样吗？
**学生已有认知**：分不清"概率分布 / 分布律 / 分布函数"这几个说法。

**讲解内容**：
- 正式写法是"分布律"（律，不是率）。
- 分布律 = 离散型随机变量取每个值的概率 $P\{X=x_k\}=p_k$（一张表，和为1）；"概率分布"是泛称（离散型用分布律，连续型用概率密度，另有分布函数）。
- 第一次讲完学生说"还是不能理解"；换成掷骰子表格 + "交通工具/自行车/汽车"类比后，学生抛出真正的困惑点（见问题2）。**症结其实是分不清分布函数和分布律。**

### 问题2：课件例5——设 $X$ 的分布函数为 $F(x)=\begin{cases}0,&x<-1\\ \tfrac14,&-1\le x<0\\ \tfrac34,&0\le x<1\\ 1,&x\ge1\end{cases}$，求 $X$ 的分布律
（来源：概率论2.1 课件例5，页码待核；手写图中第二段区间写作 $-1<x<0$，应为 $-1\le x<0$）

**学生的错误**：把 $F$ 在各段的取值 $\tfrac14,\tfrac34,1$ 直接抄成 $P\{X=-1\},P\{X=0\},P\{X=1\}$；老师答案是 $\tfrac14,\tfrac12,\tfrac14$。学生自己的卡点："x=0 时老师的答案是 1/2、x=1 是 1/4，不明白为什么"。

**讲解内容**：$F(x)=P\{X\le x\}$ 是累计概率；$P\{X=x_k\}$ = $F$ 在 $x_k$ 处的跳跃高度 $=F(x_k)-F(x_k^-)$。并指出学生原表概率之和 $=2>1$，用"和为1"即可自检。

**理解检验**：
1. 变式 $F=0\,(x<2),\ 0.3\,(2\le x<5),\ 1\,(x\ge5)$ → 学生答 $\{2:0.3,\ 5:0.7\}$ ✅ 独立做对
2. 反向：由分布律 $(-1,0,1;\ \tfrac14,\tfrac12,\tfrac14)$ 求 $F(0)$ → $\tfrac34$ ✅；求 $F(0.5)$ → 学生先答 $\tfrac12$（把单点概率 $P\{X=0\}$ 当成累计）❌，提示"哪几个取值满足 $X\le0.5$"后改为 $\tfrac34$ ✅
3. 学生追问："我怎么知道他问的是累计？" → 答：看符号，大写 $F$ 或 $\le$/"不超过" 就是累计，$P\{X=x\}$/$p_k$ 才是单点。学生随后答对 $P\{X=0.5\}=0$ 并说明"只看这个点，而 $F(0.5)$ 看累计"。
4. 变式 $F=0\,(x<1),\ 0.2\,(1\le x<3),\ 0.7\,(3\le x<4),\ 1\,(x\ge4)$ → 分布律 $\{1:0.2,\ 3:0.5,\ 4:0.3\}$ ✅；$P\{X\le3\}=0.7$ ✅；$P\{X<3\}=0.2$ ✅（并点明二者之差 $=P\{X=3\}=0.5$，即 $x=3$ 处台阶高度）

理解程度：**部分→扎实**（核心错误已被自己纠正并能说出原因，但"差分"这一步还需再练几题）。

# 补充2：2.1 例6——小概率事件重复多次（二项分布 + 补事件）

来源：概率论2.1 课件第13页例6（二项分布定义在第12页）。

**题目**：事件 A 发生的概率 $P(A)=\varepsilon$，独立重复 $n$ 次，求 A 至少发生一次的概率。

**学生已有认知**：自己先说出 $X\sim B(n,\varepsilon)$，且"至少一次 = 1 − 一次都没发生"；卡点是"套公式"（不清楚 $n,k,p,q$ 各对应什么）。

**讲解内容**：逐个符号对应（$n$=试验次数，$k=0$，$p=\varepsilon$，$q=1-\varepsilon$）；指出课件第12页第一行把 $p^k$ 印成了 $p^n$（笔误，下面的求和行才对）。
结果 $P\{X\ge1\}=1-C_n^0\varepsilon^0(1-\varepsilon)^n=1-(1-\varepsilon)^n\to1\ (n\to\infty)$。学生起初只写了最后一步，已提醒作业里要保留 $P\{X=0\}=C_n^0\varepsilon^0(1-\varepsilon)^n$ 这一步；并提醒符号写 $\varepsilon$ 不要写 $e$。

**理解检验**：
1. 合理性检验：$\varepsilon$ 小、$n\to\infty$ 时答案趋向？→ **1** ✅，并用"暗恋表白多次总会成功"自己举例，随后补充了两个前提（独立且 $\varepsilon$ 不变；$\varepsilon>0$），以及"实际推断原理"的两面（单次几乎不发生 / 大量重复迟早发生）
2. 变式 $\varepsilon=0.1$：试3次至少成功一次 → $1-0.9^3=0.271$ ✅
3. 进阶：最少试几次使概率 $>0.9$？列式 $1-0.9^n>0.9\Rightarrow 0.9^n<0.1\Rightarrow n\ln0.9<\ln0.1$。学生先写成 $n<\ln3/2$、再写成 $n<\ln0.1-\ln0.9$：**错误**（方向反了；"除"写成"减"）；并问"ln0.9 哪里是负数"（不知道 $0<x<1$ 时 $\ln x<0$）。讲解后：$n>\ln0.1/\ln0.9\approx21.85\Rightarrow n_{\min}=22$ ✅（回代：$n=21$ 时 $0.891$，$n=22$ 时 $0.902$）

理解程度：**二项分布+补事件：扎实；指数不等式取对数：需要再练**。
